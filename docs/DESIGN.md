# 溜溜 设计总纲

最后更新：2026-10-05（全书 33 关完成）。这是唯一的设计依据，改设计先改这里。

## 1. 目标

女儿读一年级（统编版语文一年级上册），起步比同学慢，有挫败感。用一个 Sprunki 式的混音游戏，覆盖整本语文书的拼音、识字和儿歌朗读，帮她追上进度，重建"我会"的信心。

成功标准不看游戏分数：她会不会主动要玩；作业里拼读、识字、朗读的问题有没有减少；老师的反馈。

## 2. 玩家与设备

- 6到7岁，喜欢 Sprunki，所有恐怖阶段都看完了，最喜欢的角色是布莱克（Black）；也喜欢软萌角色
- 大部分时间自己玩；认字不多，指示靠语音和图像
- **主力设备：电脑**，横屏，鼠标拖拽。之后再适配较新的手机（安卓也可以）
- 不再考虑旧 iPad

## 3. 核心玩法（Sprunki 式混音）

- 舞台上一排 10 个空白溜溜（原来 7 个，家长要求加多），底部是分类图标栏
- 拖乐器图标到溜溜身上，溜溜变成那个乐手，循环演奏专属声音，所有声音卡同一节拍
- 拼音关：拖声母加韵母（三拼拖三个）到同一个溜溜，它循环唱这个音节；再拖声调改变唱法。拼不到一起的组合，溜溜摇头，语音提示，退回
- 识字关：拖生字图标到溜溜身上，它唱这个字
- 儿歌关：rap 模式，见第 5 节
- 整体认读音节做成"拆不开的歌手"，一个图标直接拖上去就唱
- 点一下溜溜：静音或恢复。长按：听标准读音。右上角清空
- 支持拖拽，也支持"先点图标再点溜溜"
- **图标栏顺序每次进关随机打乱**：字宝宝、乐手、彩蛋格都打乱，不按课本顺序排（拼音关的声母韵母也一样），让她靠认字找，不靠位置记

### 词语彩蛋
- 顶部若干藏起来的词语格子，点一下播放读音
- 在台上把这个词的所有音节或字都做出来，触发彩蛋：横幅、拼音、彩纸、相关溜溜跳起来、读出词语
- 词语来自对应课文的配图词和生字词

### 闪避
点彩蛋格、长按溜溜、彩蛋播报时，整个乐队降到约两成音量，读完恢复，不完全静音。

### 语音提示从简（家长要求）
- 只保留关键的：找到彩蛋（"找到彩蛋啦"+词语）、彩蛋找够时提示进化、拼不到一起、先拼音再给声调、地图上点没打开的关、课文缺失
- 开场教学每种玩法（识字、拼音、rap、大混音）只在第一次见到时说一句
- 去掉了"天黑啦""进化啦""全找到啦"
- 唱词拖上台不再另读一遍（台上唱将会唱，叠在一起像回音）

### 切到别的窗口
- 切到别的窗口或标签页时全部暂停（乐器、唱字、唱词），切回来从原来的节拍接着放

### 语音打断
- 她点的东西（点字宝宝、点彩蛋格、长按、放字上台）马上停掉正在读的、清空排队，只读最新的
- 彩蛋播报（"找到彩蛋啦"+词语）连着读，不被系统提示插队，但她点别的照样打断
- 系统提示（"彩蛋找够啦"、"进化啦"、"天黑啦"）等当前读完再说；期间她点了别的就跳过，不补播
- 放字上台正好凑成彩蛋时，直接播报彩蛋，不先读那个字

## 4. 阶段

- **一课一个阶段，完全按课本顺序**，约 33 个阶段，加若干语文园地彩蛋关
- **不按学习进度锁**：找到当前阶段足够的彩蛋（默认 4 个里找到 3 个）就解锁下一个
- **已解锁的阶段可以在阶段地图里任意切换**
- 进化：闪光加音效，所有角色换形态，所有乐器换一套声音，图标栏换内容，换一组彩蛋。进化按钮亮起时保留聚光灯提示；不需要开场引导
- **恐怖阶段提前，反复出现、逐步加强**：第 3 阶段第一次出现，之后每隔三四个阶段一次，最后是终极恐怖
- 每个阶段先定风格，角色挂件和音效都跟着风格走（例如海底：潜水镜、海草、气泡、水声回响）

## 5. 儿歌 rap 模式

- 每一句是一个唱词图标，拖到溜溜身上，这个溜溜负责唱这一句
- 台上从左到右轮流唱，一句占两小节，乐器伴奏
- 按正确顺序排好整首连起来，触发大彩蛋，全场表演一遍。排错照样唱，让她自己发现调整
- **歌词屏**：舞台背景显示整首诗，每字标拼音。没录的句子灰色，录好的变亮；正在唱的句子逐字高亮（卡拉OK）；每句旁边标是哪个溜溜在唱。歌词屏样式跟阶段风格变（卷轴、霓虹灯牌、滴落闪烁等）
- **录音室（先录后玩）**：歌词屏高亮第一句，有现成音频的先读一遍；她按大录音键，倒数 3 2 1，读完松开或停顿一秒自动结束；立刻回放，选"好了"或"再录"；自动跳下一句。可以录一部分先去玩，以后再补
- **唱将角色家族**：同一基础造型，每句自动分配不同颜色和编号（最多 12 句）；图标显示这句的前两三个字；她自己录的句子带小麦克风标记；每首诗一个主题挂件（如咏鹅的白羽毛）；随阶段一起进化
- **自由录音**：不需要文字，录任意声音变成图标拿去混音
- **变声**：录音跟着阶段风格变声，恐怖阶段低沉阴森，太空阶段机器人音

## 6. 声音

- 乐器：Python 离线制作（tools/render_loops.py），风格统一，无授权问题。110 BPM，32 个十六分音符一个循环，按阶段风格换调式、音色、节奏型
- 拼音、识字读音：edge-tts 成年女声，选定 zh-CN-XiaoxiaoNeural（晓晓），语速 -35%
- 公共领域古诗、绕口令：edge-tts 童声（content/poems.json），选定 zh-CN-XiaoyiNeural（晓伊）原音高，语速 -30%。edge-tts 没有真正的中文童声，晓伊最接近
- 单个声母、音节直接把带调拼音（如 bō、dē、rì）交给 edge-tts，家长试听 22 个声母全部正确；不用同音字代替
- 其他儿歌课文：孩子自己录（或家长录）
- 朗读音频由脚本拉伸压缩到正好两小节
- edge-tts 多音字会读错，生成后要人工听
- 正式版音频：乐器循环按风格分套放 audio/loops/<套名>/<乐器>.flac（FLAC 无损，没有编码器延迟，能无缝循环，各浏览器都能解码），每套约 1MB，进阶段时才加载。读音放 audio/voice/（z 单字、w 词语、ui 提示语），mp3
- 乐器声音套：1 天和地（明亮流行）、wx 金木水火土（五声调式、古筝、木鱼、八音盒）、2 恐怖、sc 日月山川（笛子、水滴、柔和）。tools/render_loops.py 里 bright_set() 一个函数出一整套，以后加风格只要换参数
- 单字读音也用拼音生成（tools/gen_voice.py），词语和提示语用汉字；生成后打开 build/voice-check.html 逐个试听
- 唱字：识字歌手每个位置在自己的拍子上唱（7 个位置错开），每次音高略变，像在唱歌
- 拼音歌手循环人声由 edge-tts 音频对齐节拍生成，替换目前的合成哼唱

O P L M → ū ú ǔ ù
N B V C → ǖ ǘ ǚ ǜ

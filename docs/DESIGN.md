# 溜溜 设计总纲

最后更新：2026-10-05。这是唯一的设计依据，改设计先改这里。

## 1. 目标

女儿读一年级（统编版语文一年级上册），起步比同学慢，有挫败感。用一个 Sprunki 式的混音游戏，覆盖整本语文书的拼音、识字和儿歌朗读，帮她追上进度，重建"我会"的信心。

成功标准不看游戏分数：她会不会主动要玩；作业里拼读、识字、朗读的问题有没有减少；老师的反馈。

## 2. 玩家与设备

- 6到7岁，喜欢 Sprunki，看了很久，习惯恐怖阶段；也喜欢软萌角色
- 大部分时间自己玩；认字不多，指示靠语音和图像
- **主力设备：电脑**，横屏，鼠标拖拽。之后再适配较新的手机（安卓也可以）
- 不再考虑旧 iPad

## 3. 核心玩法（Sprunki 式混音）

- 舞台上一排 7 个空白音豆，底部是分类图标栏
- 拖乐器图标到音豆身上，音豆变成那个乐手，循环演奏专属声音，所有声音卡同一节拍
- 拼音关：拖声母加韵母（三拼拖三个）到同一个音豆，它循环唱这个音节；再拖声调改变唱法。拼不到一起的组合，音豆摇头，语音提示，退回
- 识字关：拖生字图标到音豆身上，它唱这个字
- 儿歌关：rap 模式，见第 5 节
- 整体认读音节做成"拆不开的歌手"，一个图标直接拖上去就唱
- 点一下音豆：静音或恢复。长按：听标准读音。右上角清空
- 支持拖拽，也支持"先点图标再点音豆"

### 词语彩蛋
- 顶部若干藏起来的词语格子，点一下播放读音
- 在台上把这个词的所有音节或字都做出来，触发彩蛋：横幅、拼音、彩纸、相关音豆跳起来、读出词语
- 词语来自对应课文的配图词和生字词

### 闪避
点彩蛋格、长按音豆、彩蛋播报时，整个乐队降到约两成音量，读完恢复，不完全静音。

## 4. 阶段

- **一课一个阶段，完全按课本顺序**，约 33 个阶段，加若干语文园地彩蛋关
- **不按学习进度锁**：找到当前阶段足够的彩蛋（默认 4 个里找到 3 个）就解锁下一个
- **已解锁的阶段可以在阶段地图里任意切换**
- 进化：闪光加音效，所有角色换形态，所有乐器换一套声音，图标栏换内容，换一组彩蛋。进化按钮亮起时保留聚光灯提示；不需要开场引导
- **恐怖阶段提前，反复出现、逐步加强**：第 3 阶段第一次出现，之后每隔三四个阶段一次，最后是终极恐怖
- 每个阶段先定风格，角色挂件和音效都跟着风格走（例如海底：潜水镜、海草、气泡、水声回响）

## 5. 儿歌 rap 模式

- 每一句是一个唱词图标，拖到音豆身上，这个音豆负责唱这一句
- 台上从左到右轮流唱，一句占两小节，乐器伴奏
- 按正确顺序排好整首连起来，触发大彩蛋，全场表演一遍。排错照样唱，让她自己发现调整
- **歌词屏**：舞台背景显示整首诗，每字标拼音。没录的句子灰色，录好的变亮；正在唱的句子逐字高亮（卡拉OK）；每句旁边标是哪个音豆在唱。歌词屏样式跟阶段风格变（卷轴、霓虹灯牌、滴落闪烁等）
- **录音室（先录后玩）**：歌词屏高亮第一句，有现成音频的先读一遍；她按大录音键，倒数 3 2 1，读完松开或停顿一秒自动结束；立刻回放，选"好了"或"再录"；自动跳下一句。可以录一部分先去玩，以后再补
- **唱将角色家族**：同一基础造型，每句自动分配不同颜色和编号（最多 12 句）；图标显示这句的前两三个字；她自己录的句子带小麦克风标记；每首诗一个主题挂件（如咏鹅的白羽毛）；随阶段一起进化
- **自由录音**：不需要文字，录任意声音变成图标拿去混音
- **变声**：录音跟着阶段风格变声，恐怖阶段低沉阴森，太空阶段机器人音

## 6. 声音

- 乐器：Python 离线制作（tools/render_loops.py），风格统一，无授权问题。110 BPM，32 个十六分音符一个循环，按阶段风格换调式、音色、节奏型
- 拼音、识字读音：edge-tts 成年女声，选定 zh-CN-XiaoxiaoNeural（晓晓），语速 -35%
- 公共领域古诗、绕口令：edge-tts 童声（content/poems.json），选定 zh-CN-XiaoyiNeural（晓伊）原音高，语速 -30%。edge-tts 没有真正的中文童声，晓伊最接近
- 单个声母、音节直接把带调拼音（如 bō、dē、rì）交给 edge-tts，家长试听 22 个声母全部正确；不用同音字代替
- 其他儿歌课文：孩子自己录（或家长录）
- 朗读音频由脚本拉伸压缩到正好两小节
- edge-tts 多音字会读错，生成后要人工听
- 正式版音频拆成单独压缩文件，按阶段加载；注意压缩格式的编码器延迟会破坏无缝循环，用 loopStart/loopEnd 处理
- 拼音歌手循环人声由 edge-tts 音频对齐节拍生成，替换目前的合成哼唱

## 7. 角色

- 11 个原创乐手：节奏（咚咚 鼓、嚓嚓 沙锤、啪啪 拍手、嘣嘣 贝斯），音效（叮叮、呜呜、嘀嘟），旋律（铃铃、嘟嘟、呼呼、啦啦），外加拼音歌手、识字歌手、唱将家族
- **完整身体**：头、身体、手臂、腿
- **部件组合系统**：固定骨架加可替换零件（眼睛、嘴、手脚、挂件、恐怖元素），每个阶段给每个角色挑一套不同组合，挂件贴合阶段风格
- 恐怖元素每个角色分配不同的：心脏外露、眼球掉出挂着、缝线、绷带、裂开、融化、多眼等
- 全部原创。不复刻任何 Sprunki 角色的外形或声音，也不在原版角色上改细节冒充原创。不用 Hello Kitty、美乐蒂等版权形象。不搬课本插图

## 8. 其他功能

- 录歌：录下当前混音，最长 30 秒，存进"我的歌"，持久保存
- 家长入口（大人才进得去）：录入儿歌文字（只存本机）、看错误记录、导出记录
- 时长控制细则待定

## 9. 版权与隐私

- 网站在 GitHub Pages 上是公开的
- 仓库里只放公共领域文本（古诗、传统绕口令）和课本里的短词
- 课本 PDF 只放在本地 private/ 目录，不提交到仓库
- 现代作者的儿歌课文全文不进仓库：家长在游戏里录入，只存本机
- 孩子的录音只存本机，不上传
- 不放孩子的名字、照片

## 10. 技术

- 单页网页应用，托管 GitHub Pages，电脑浏览器为主（Chrome、Edge、Safari），可装成 PWA 离线用
- 不需要登录
- 存档、录音、家长录入的文字用 IndexedDB 存本机
- 麦克风用 getUserMedia（https 下可用）
- 音频按阶段加载，避免一次加载几十 MB

## 12. 已定的决定

- 不计时、不排行、没有失败惩罚、不做抽奖开箱
- 出错给提示，不打红叉
- 内容严格跟课本：整体认读不拆，声母不含 k
- 干扰项和对比用课本"比一比"：b/d、f/t、z/zh、c/ch、s/sh、ie/ei、iu/ui
- 允许恐怖风格（家长决定）
- 工作方式：先讨论设计，家长说开始再动手；中文，简洁直接
